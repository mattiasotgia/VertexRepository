# Validation notebooks for the DL Vertex ICARUS implementation

This directory contain all the notebooks to plot/visualize/validate the vertex performance with the ICARUS detector implementation. 


## Setup on EAF

To use the notebooks in this directory, it is required to have on EAF a `pixi` environment, provided with the included `pixi.toml` file. 

To install the required python modules, just run `pixi install`. Then, all the notebooks running from whithin the same directory (or sub-directories) will pick up the `pixi` environment and relative packages.
