# Vertex DL implementation

# Utilities 

Setting up the workspace using `setup.sh` will define a couple of utilities

- `merge_productions.sh` this is useful to merge `csv` files output of the vertex training passes (both pass1 and pass2). Usage (`merge_productions.sh -h`) is `merge_productions.sh -o <NAME_OF_FILES> -v <VIEWS> [-h]`
